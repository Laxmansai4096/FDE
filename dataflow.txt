3. STEP-BY-STEP TECHNICAL STAGE WALKTHROUGH
-------------------------------------------

STAGE 1: Ingress & Enterprise Security Screening
- User submits a query or clicks a 1-click instant order button.
- Azure APIM checks tenant quotas (`x-tenant-id`) and enforces rate limits.
- Azure AI Content Safety filters harmful categories.
- Dual-Layer Guardrail Engine (server/gateway.js):
  * Layer 1 (PII Scrubbing): Redacts emails (`buyer@aura.com`), phone numbers (`+91 98765 43210`),

  * Layer 2 (Security Guardrails): Scans for prompt injection attacks (`"ignore previous instructions"`, 
    `"DROP TABLE"`, `"shutdown"`). Intercepts threats in 0ms before reaching LLMs.

STAGE 2: Intent Interception & Specialized Execution
The request enters the Intent Interceptor (server/index.js), which routes queries to specialized sub-engines:
- Human-in-the-Loop (HITL) Concierge Handoff: Transfers complex VIP corporate gifting, custom 
  bulk requests, or complaints to Senior Atelier Master Vikramaditya Sharma (`TICKET-HUMAN-7702`).

  cancellations. Features token-overlap title matching and inventory stock decrementing.
- Autonomous ReAct Agent (server/agent.js): Formulates custom haute perfume oil ratios via multi-step 
  reasoning (`tool_create_bespoke_formula`).
- Royal Perfumery AI Committee (server/autogen_team.js): Coordinates 4 specialized agents 
  (Master Perfumer, Inventory Manager, Chemist, Safety Director) to issue a Royal Unanimous Certificate.

STAGE 3: Semantic Vector Cache Probe (Fast-Path)
For recommendation queries, the system probes the Semantic Vector Cache:
- Calculates cosine similarity between prompt query vector and cached entries.
- Cache HIT (>= 0.90 similarity): Returns response instantly in 0ms at $0.00 token cost.
- Cache MISS: Passes query to HyDE and Hybrid RAG retrieval.

STAGE 4: HyDE Query Expansion & 6D Vector RAG
- HyDE Query Expansion (server/hyde.js): Expands short prompts into rich sensory descriptions.
- 6D Scent Vector Encoding: Vectorizes scent attributes across 6 dimensions.
- Hybrid RAG & Knowledge Graph (server/rag.js & db.js): Combines vector similarity with relational 
  filters (max price, season, in-stock status) and Knowledge Graph note pairings.

STAGE 5: Multi-Region Load Balancing & Circuit Breaker Failover
- Round-Robin Load Balancer: Distributes requests evenly across 3 regional replicas (US-East, EU-West, AP-South).
- Circuit Breaker Failover (server/gateway.js):
  * Monitored states: CLOSED (Healthy), HALF-OPEN (Probing), OPEN (Outage).
  * On provider failure, traffic automatically failovers:
    Google Gemini 1.5 Flash ──► Azure OpenAI GPT-4o ──► Anthropic Claude 3.5 Sonnet

STAGE 6: Telemetry Audit & n8n Visual Node Canvas Rendering
- FDE Ops Telemetry (server/telemetry.js): Logs metrics, latency, token spend, and trace spans.
