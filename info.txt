1. PROJECT BACKGROUND & BUSINESS CONTEXT
--------------------------------------------------------------------------------
AURA Royal Perfumery India is a premier luxury fragrance house specializing in bespoke 
Indian attars, rare botanical extraits, and royal accords (Assam Oud, Sacred Mysore 
Sandalwood, Kashmir Saffron, Kannauj Damask Rose, Malabar Citrus, Khus Vetiver).

To scale its digital e-commerce presence, AURA deployed an AI-powered natural language 
Scent Sommelier & Customer Support Assistant. However, early off-the-shelf LLM prototypes 
failed enterprise readiness:
1. PII Security Leaks: Customers submitting emails/cards had data logged in plain text.
2. Out-of-Stock Hallucinations: LLMs recommended out-of-stock items, causing order cancels.
3. High API Bills & Slow Speed: Duplicate customer queries cost $0.0003 each with 2-3s delay.
4. Support Workflow Failures: LLMs could not track order shipments (ORD-8821) or execute cancellations.
5. Vulnerability to Jailbreaks: Indirect prompt injections ("DAN mode", obfuscated emails) bypassed standard keyword filters.

2. THE 13 ENTERPRISE FDE REQUIREMENTS & ARCHITECTURAL SOLUTION
--------------------------------------------------------------------------------

FEATURE 1: LLM GATEWAY, DUAL-LAYER PII SCRUBBING & SECURITY GUARDRAILS (server/gateway.js)
- Requirement: Ingress security proxy with static regex + LLM Security Classifier.
- Functionality: Scrubs standard and obfuscated emails (`buyer [at] domain [dot] com`), cards (`[REDACTED_CARD]`), and blocks indirect prompt injections / roleplay jailbreaks.

FEATURE 2: GATEWAY SEMANTIC VECTOR CACHING LAYER (server/gateway.js)
- Requirement: Sub-15ms prompt response caching for repeated/paraphrased queries.
- Functionality: Computes 6D Scent Accord Vector -> Cosine Similarity >= 0.88 -> Returns cached response in 0ms with $0.00 token cost. Bypasses PII prompts to prevent cache collision.

FEATURE 3: 6D SCENT ACCORD VECTOR SPACE & HYBRID RAG (server/db.js & server/rag.js)
- Requirement: Mathematical scent accord vector space `[Citrus, Woody, Floral, Oriental, Gourmand, Fresh]` merged with relational SQL catalog filters.
- Indian Fragrance Catalog:
  1. Royal Oud & Mysore Sandalwood (₹18,500 / $245) - Assam Oud & Mysore Sandalwood
  2. Solar Malabar Citrus & Vetiver (₹14,500 / $195) - Malabar Lemon & Coastal Vetiver
  3. Royal Kashmir Saffron & Amber (₹21,000 / $280) - Kashmir Saffron & Madagascar Vanilla
  4. Imperial Kannauj Rose & Suede (₹19,500 / $235) - Kannauj Damask Rose & White Suede
  5. Monsoon Vetiver & Rain Mint (₹16,000 / $210) - Earthy Indian Khus Vetiver & Petrichor
  6. Smoked Cardamom & Incense (₹22,500 / $295) - Kerala Black Cardamom & Temple Incense

FEATURE 4: HyDE & RECIPROCAL RANK FUSION (RRF) RETRIEVAL (server/hyde.js)
- Requirement: Resolve 1-2 word vague search queries ("Fresh morning").
- Functionality: LLM generates hypothetical ideal product description -> Fuses vector rank + sparse BM25 rank using Reciprocal Rank Fusion (RRF).

FEATURE 5: AUTONOMOUS REACT MULTI-AGENT TOOL CALLING ENGINE (server/agent.js)
- Requirement: Dynamic tool invocation loop (`[THOUGHT]` -> `[ACTION]` -> `[OBSERVATION]`).
- Registered Tools: `tool_create_bespoke_formula`, `tool_check_inventory`, `tool_graph_harmonize`, `tool_place_order`, `tool_check_order_status`, `tool_cancel_order`.

FEATURE 7: E-COMMERCE CUSTOMER SUPPORT & ORDER OMS ENGINE (server/orders.js)
